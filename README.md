# Radio Caprichos · web

Web nueva de RadioCaprichos.com: 7 emisoras con los colores de la bandera del Cusco.

- `index.html` · plantilla única
- `i18n/es.json`, `i18n/fr.json` · textos en español (es-PE) y francés (fr-FR)
- `css/caprichos.css` · estilos chicha (paleta del Cusco + fucsia #F52AAE)
- `js/app.js` · idioma, emisoras y reproductor
- `data/emisoras.json` · emisoras, colores y fuentes de audio

Producción (NUC) no se toca hasta validar en staging.
